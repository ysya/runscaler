Scale sets

02 / CACHE

Native Actions cache

Optional, private cache receiver for supported runner images. Docker scale sets can also use an external endpoint.

A stock runner image is not cache-capable. Set up a supported image and a private address before enabling this receiver. Setup guide ↗

Host-wide cleanup under disk pressure. Tier 4 can wipe legacy cache volumes.

TOML

Finish on your host

Save the file, add your PAT locally or place the GitHub App private key at the chosen path, then run runner validate. Protect the file with mode 0600. The usual paths are /etc/runner/config.toml on Linux and ~/.config/runner/config.toml for a macOS user service.

Follow the deployment guide ↗ for Docker or Tart.
