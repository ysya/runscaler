設定工具

產生 config.toml。

選擇規模集、快取和主機設定，複製 TOML 後再於自己的主機加入憑證並驗證。

● 不輸入或傳送憑證開始設定 ↓
規模集Actions 快取磁碟保護程序設定

01 / RUNNERS

規模集

每個規模集連接一個 GitHub 組織或儲存庫。

02 / CACHE

內建 Actions 快取

供相容 runner 映像檔使用的私人快取接收端。Docker 規模集也可以使用外部接收端。

一般 runner 映像檔不支援這個快取。啟用前請準備相容映像檔和私人位址。設定指南 ↗

03 / STORAGE

磁碟空間保護

主機空間不足時清理快取。第 4 級可能清空舊版 cache volume。

04 / PROCESS

全域設定

紀錄、健康檢查、同時執行數量與診斷設定會套用至整個程序。

你的設定檔

config.toml

TOML

在主機完成設定

存檔後在主機上填入 PAT，或將 GitHub App 私鑰放在指定路徑，接著執行 runner validate。請將檔案權限設為 0600。Linux 系統服務常用 /etc/runner/config.toml；macOS 使用者服務常用 ~/.config/runner/config.toml。

Docker 與 Tart 安裝方式請參閱部署指南 ↗。
