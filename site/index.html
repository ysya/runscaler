THE IDEA

Capacity follows the queue.

Keep your own host and workflow. Runscaler handles the runner lifecycle between them.

01 / LISTEN

Wait for real work

Long-poll the GitHub scale-set API and start runners in response to assigned jobs.

02 / RUN

Choose the right host

Use Docker containers on a Docker host or Tart virtual machines for macOS and Linux jobs.

03 / RECOVER

Leave a clean slate

Each runner handles one job. Runscaler removes it afterward and reconciles resources after a restart.

GET STARTED

Configure every part of your runner.

Use the dedicated config builder for scale sets, native or external Actions cache, Docker and Tart settings, disk cleanup, and diagnostics. Copy TOML and validate it on your host.
