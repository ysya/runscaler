セルフホスト型 GITHUB ACTIONS

GitHub Actions ランナー。Kubernetes は不要。

Runscaler は、自分のホスト上で GitHub Actions のジョブに応じて Docker コンテナや Tart VM を起動します。Go の実行ファイル 1 つで、ジョブの到着からランナーの削除まで管理します。

仕組み

キューに合わせて実行容量を調整。

使い慣れたホストとワークフローはそのままに。Runscaler がランナーのライフサイクルを管理します。

01 / 待機

ジョブが来たら起動

GitHub のスケールセット API をロングポーリングし、割り当てられたジョブに応じてランナーを起動します。

02 / 実行

ホストに合った環境を選択

Docker ホストではコンテナを、macOS や Linux のジョブには Tart VM を使用できます。

03 / 回収

ジョブ完了後にクリーンアップ

各ランナーは 1 つのジョブを処理した後に削除されます。再起動時には残存リソースも整理します。

はじめる

ランナーの設定をまとめて作成。

設定ツールでは、スケールセット、内蔵・外部 Actions キャッシュ、Docker と Tart のオプション、ディスクのクリーンアップ、診断を設定できます。生成した TOML をコピーし、ホスト上で検証してください。
