自架 GITHUB ACTIONS RUNNER

工作來了，runner 就緒。

一個程序在你的主機上依工作需求啟動 Docker 容器或 macOS VM。每個 runner 只執行一個工作，完成後便會移除。

運作原理

容量跟著工作佇列走。

沿用你的主機與工作流程；Runscaler 負責中間的 runner 生命週期。

01 / 等待

有工作才啟動

透過 GitHub scale-set API 長輪詢，在收到工作指派時啟動 runner。

02 / 執行

依主機選擇環境

在 Docker 主機使用容器；macOS 工作則可使用 Tart VM。

03 / 回收

工作結束後清理

每個 runner 只處理一個工作。完成後會移除，重新啟動時也會清理遺留資源。

開始使用

選好主機設定，複製即可使用。

選擇基本選項並複製 TOML。在主機上填入憑證，再用 runner validate 檢查實際環境。

在主機完成設定

複製、存檔、驗證、執行。

網頁只產生設定文字；runner 會檢查主機與 GitHub 存取權。

01

安裝

先啟動 Docker，再於 Linux 安裝 runner 執行檔。

curl -fsSL https://raw.githubusercontent.com/ysya/runscaler/main/install.sh | sudo sh
02

存檔並填入憑證

將 TOML 貼到檔案，在主機填入 PAT 或放置 App 私鑰檔案，再保護設定檔。

sudo install -d -m 0700 /etc/runner
sudoedit /etc/runner/config.toml
sudo chmod 0600 /etc/runner/config.toml
03

安裝服務

新的系統服務會在啟動前檢查 Docker 與 GitHub 存取權。

sudo /usr/local/bin/runner service install --config-path /etc/runner/config.toml
sudo /usr/local/bin/runner status
01

準備 Mac

安裝 Tart 並拉取相容的 VM 映像檔，接著在本機圖形介面登入階段安裝 runner 執行檔。

curl -fsSL https://raw.githubusercontent.com/ysya/runscaler/main/install.sh | sh -s -- --user
02

存檔並填入憑證

將 TOML 貼到檔案，在主機填入 PAT 或放置 App 私鑰檔案，再保護設定檔。

mkdir -p ~/.config/runner
chmod 0700 ~/.config/runner
nano ~/.config/runner/config.toml
chmod 0600 ~/.config/runner/config.toml
03

驗證並安裝

請在 macOS 本機登入階段執行。

~/.local/bin/runner validate
~/.local/bin/runner service install --scope user
~/.local/bin/runner status
