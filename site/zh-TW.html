運作原理

容量跟著工作佇列走。

沿用你的主機與工作流程；Runscaler 負責中間的 runner 生命週期。

01 / 等待

有工作才啟動

透過 GitHub scale-set API 長輪詢，在收到工作指派時啟動 runner。

02 / 執行

依主機選擇環境

在 Docker 主機使用容器；macOS 與 Linux 工作可使用 Tart VM。

03 / 回收

工作結束後清理

每個 runner 只處理一個工作。完成後會移除，重新啟動時也會清理遺留資源。

開始使用

完整設定你的 runner。

獨立設定工具涵蓋多個規模集、內建或外部 Actions 快取、Docker 和 Tart 選項、磁碟清理與診斷。複製 TOML 後在主機上驗證。
